BUILT IN THE OPEN

Early days.
Real hardware.

Boxpool is under active development. Mac uses Apple’s Virtualization framework; Linux uses Firecracker, with a Docker fallback that provides weaker isolation. Mac releases are ad-hoc signed, not notarized.

Read the trust model before running untrusted workloads. The docs follow main and mark unreleased features.
