Boxpool

Turn your spare Linux machines and Apple silicon Macs into sandboxes for AI agents.

Install an early release on Linux or Apple silicon macOS:

curl -fsSL https://boxpool.run/install | sh
boxpool doctor

Or use Homebrew: brew install sukhendu2002/tap/boxpool, or Node.js 20+: npx boxpool doctor.

After checking host prerequisites, run sudo boxpool up on Linux (client commands also need sudo) or boxpool up as your user on macOS.

The macOS binary is ad-hoc signed and is not notarized. See verification and Gatekeeper instructions.
